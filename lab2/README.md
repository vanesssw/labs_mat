# Архиватор ЛР №2 «Методы упаковки данных»

Программа-архиватор и разархиватор файлов. Сжатие **без потерь**: после распаковки получается ровно тот же файл, байт в байт. Реализованы четыре метода из методических указаний:

| Метод | Идея | Где хорош |
|---|---|---|
| **RLE** (running) | серия из L > 3 одинаковых байтов → три байта «байт, флаг, L» | длинные повторы: однотонные области картинок, пробелы, нули |
| **Хаффман** | частым байтам — короткие коды, редким — длинные (дерево снизу вверх) | неравномерные частоты байтов (тексты) |
| **Шеннон–Фано** | то же, но дерево строится сверху вниз делением на группы с равными суммами частот | для сравнения с Хаффманом (ЛР №1) |
| **LZW** | повторяющиеся цепочки байтов заменяются номерами в словаре, который строится на лету | тексты, таблицы, логи, картинки — всё, где повторяются целые фрагменты |

Входной алфавит — все 256 значений байта (полный набор ASCII), поэтому сжимать можно файлы любого типа.

## Требования

Только Python 3.8 или новее (проверено на 3.12). Сторонние библиотеки не нужны: интерфейс сделан на `tkinter`, который входит в стандартную поставку Python для Windows.

## Графический интерфейс

Запуск — двойной щелчок по **`start_gui.bat`** или команда из папки `lab2`:

```
python gui.py
```

### Вкладка «Архиватор» — сжать или распаковать файл

1. Нажмите **«Выбрать файл…»** (окно сразу открывает папку `test_files` с тестовыми файлами).
2. Выберите метод: RLE, Хаффман, Шеннон–Фано, LZW или **«Авто»** (программа сожмёт файл всеми методами и оставит самый маленький результат).
3. Нажмите **«Сжать → .lab2»**. Рядом с файлом появится архив `<имя файла>.lab2`. Программа покажет исходный размер, размер архива, его долю в процентах и коэффициент сжатия k = V_исх / V_сж. Зелёная полоска — файл уменьшился, красная — увеличился.
4. После сжатия в поле файла автоматически подставляется архив: нажмите **«Распаковать .lab2»**. Восстановленный файл сохранится рядом. Если файл с таким именем уже есть, к имени добавится « (1)», и оригинал не будет перезаписан. При распаковке программа сверяет контрольную сумму CRC-32 и сообщает, что данные восстановлены без искажений.

### Вкладка «Сравнение методов» — какой метод лучше для каких данных

1. Нажмите **«Тестовый набор»**, чтобы добавить все файлы из `test_files`, или **«Добавить файлы…»**, чтобы выбрать свои.
2. Нажмите **«▶ Сравнить методы»**. Каждый файл сжимается всеми четырьмя методами и тут же распаковывается для проверки.
3. В таблице для каждого файла показаны:
   - размер;
   - энтропия H₀ (по частотам байтов) и H₁ (с учётом предыдущего байта), бит/байт;
   - предел n·H₀/8 — меньше этого размера Хаффман и Шеннон–Фано сжать не могут;
   - размер архива каждым методом в % от исходного: ▼ — файл уменьшился, ▲ — увеличился;
   - лучший метод.
4. Щелчок по строке рисует внизу два графика: размеры архивов по методам и гистограмму частот байтов выбранного файла.

### Вкладка «Как это работает» — алгоритм по шагам

Введите короткое сообщение (до 400 символов) или выберите готовый **пример** из списка: примеры из методички, «абракадабра», TOBEORNOTTOBEORTOBEORNOT и другие. Выберите метод — слева появится пошаговое решение, справа рисунок.

- **Хаффман / Шеннон–Фано**: частоты и вероятности, энтропия H, Hmax, избыточность, шаги построения дерева, коды символов, средняя длина lср, коэффициенты Kсс и Kоэ, проверка H ≤ lср < H + 1 и неравенства Крафта, закодированное сообщение. Справа — кодовое дерево.
- **LZW**: начальный словарь, таблица кодирования в обозначениях методички (символ, sK, выход, добавление в словарь), таблица декодирования, размер результата. Справа — словарь в виде дерева цепочек.
- **RLE**: выбор байта-флага, серии, закодированный поток, размер. Справа — сжатый поток побайтно.

## Командная строка

Все команды запускаются из папки `lab2`.

```
python archiver.py compress   <файл> [-m метод] [-o архив]   сжать (короткая форма: c)
python archiver.py decompress <архив.lab2> [-o файл]         распаковать (x)
python archiver.py info       <файл>                         энтропия и характеристики кодов (i)
python archiver.py bench      <файлы или папки>              сравнить все методы (b)
```

Методы для `-m`: `rle`, `huffman` (по умолчанию), `shannon`, `lzw`, `auto`.

Примеры:

```
python archiver.py c test_files\01_text_ru_cp1251.txt -m lzw
python archiver.py x test_files\01_text_ru_cp1251.txt.lab2
python archiver.py i test_files\01_text_ru_cp1251.txt
python archiver.py b test_files
```

## Формат файла .lab2

| Смещение | Размер, байт | Поле |
|---|---|---|
| 0 | 4 | сигнатура `LAB2` |
| 4 | 1 | версия формата (1) |
| 5 | 1 | метод: 1 — RLE, 2 — Хаффман, 3 — Шеннон–Фано, 4 — LZW |
| 6 | 8 | размер исходных данных |
| 14 | 4 | CRC-32 исходных данных |
| 18 | 2 | длина имени исходного файла L |
| 20 | L | имя исходного файла (UTF-8) |
| 20 + L | … | сжатые данные |

Что лежит в сжатых данных:
- **RLE** — 1 байт-флаг, затем закодированный поток.
- **Хаффман и Шеннон–Фано** — число различных байтов N − 1, затем N пар «байт, длина кода», затем битовый поток. Коды канонические, поэтому дерево хранить не нужно.
- **LZW** — поток кодов переменной длины от 9 до 16 бит; код 256 означает очистку словаря.

## Тесты

```
python -m unittest discover -s tests -v
```

25 тестов проверяют:
- что каждый метод точно восстанавливает данные на трудных случаях: пустой файл, один байт, серии длиннее 255, все 256 значений байта, случайные данные, случай «sKsKs» в LZW, переполнение словаря LZW;
- что результаты совпадают с примерами из методички: 40 пробелов → 3 байта; коды Хаффмана для A…F; таблица LZW для «абабвбабабааааааа»;
- теоретические свойства: H ≤ lср < H + 1; код Шеннона–Фано никогда не короче кода Хаффмана; сумма Крафта равна 1;
- что повреждённый архив обнаруживается по CRC-32.

Пересоздать тестовые файлы: `python tools/make_test_files.py`.
