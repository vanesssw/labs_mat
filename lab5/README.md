# ЛР №5 «Генераторы псевдослучайных чисел»

Программа реализует семь датчиков псевдослучайных чисел — от метода середины квадрата фон Неймана до вихря Мерсенна и криптостойкого Блюма–Блюма–Шуба. Качество последовательностей проверяется батареей из 14 статистических тестов.

Все датчики и тесты написаны с нуля. Проверка корректности:
- вихрь Мерсенна побитно совпадает со встроенным модулем `random` Python;
- p-значения тестов NIST совпадают с контрольными примерами стандарта NIST SP 800-22.

| Датчик | Формула | Что показывает |
|---|---|---|
| Середина квадрата (фон Нейман) | средние цифры xₙ² | быстро вырождается: 5772 → … → 0 за 7 шагов |
| ЛКГ: учебный, RANDU, ANSI C, MINSTD, Numerical Recipes, свой | xₙ₊₁ = (a·xₙ + c) mod m | теорема Халла–Добелла, плохие младшие биты, плоскости RANDU |
| РСЛОС 16 и 32 бит | XOR отводов, примитивный многочлен | период 2ⁿ − 1, но линейная сложность всего n |
| Xorshift32 | три «сдвига и XOR» | быстрый и статистически хороший |
| Вихрь Мерсенна MT19937 | скручивание 624 слов + закалка | стандарт Python, период 2¹⁹⁹³⁷ − 1 |
| Блюм–Блюм–Шуб | xₙ₊₁ = xₙ² mod pq | криптостойкий, но медленный |
| Эталоны: `random`, `os.urandom` | — | для сравнения |

Тесты:
- **по битам, NIST SP 800-22:** частотный, частотный в блоках, серии, самая длинная серия единиц, кумулятивные суммы, приближённая энтропия;
- **по числам, по Кнуту:** χ² Пирсона, Колмогоров–Смирнов, сериальный для пар и троек, покер-тест, автокорреляция, Монте-Карло для π;
- **дополнительно:** тест младшего бита чисел.

## Требования

Python 3.8 или новее (проверено на 3.12), библиотеки **numpy** и **Pillow** (`pip install numpy pillow`, если их нет). Интерфейс на `tkinter`.

## Графический интерфейс

Запуск — двойной щелчок по **`start_gui.bat`** или `python gui.py` из папки `lab5`.

### Вкладка «Генератор»
Выберите датчик и зерно (seed). Для пункта «Свой ЛКГ» задайте a, c, m. Нажмите **«Сгенерировать»**.
- Слева — формула и первые шаги по ней, для ЛКГ ещё проверка условий Халла–Добелла и найденный период.
- Справа — гистограмма, диаграмма пар (uₙ, uₙ₊₁) и картинка 128×128 из бит. Режим «младший бит чисел» у ЛКГ с модулем 2ᵏ показывает вертикальные полосы: младший бит чередуется 0101….

### Вкладка «Проверка качества»
Выберите объём выборки («быстро» или «как в NIST») и нажмите **«Запустить тесты»**. Таблица покажет p-значения и итог по каждому тесту (α = 0,01), график — величину −lg p: красные полосы — непройденные тесты. Ниже объяснено, что проверяет каждый тест.

### Вкладка «Сравнение»
**«Сравнить все датчики»** — все 13 датчиков через одни и те же тесты, плюс линейная сложность. Внизу — значение 9uₖ − 6uₖ₊₁ + uₖ₊₂: у RANDU все точки лежат на 15 прямых (тройки чисел — на 15 плоскостях), у вихря Мерсенна — сплошное облако.

## Командная строка

```
python prngtool.py list                       список датчиков
python prngtool.py gen mt -n 10 --seed 42     первые числа (совпадают с random.Random(42).getrandbits(32))
python prngtool.py explain randu              как работает датчик
python prngtool.py test randu                 тесты качества
python prngtool.py test mt --big              выборка как в NIST
python prngtool.py compare                    сравнить все датчики
python prngtool.py lcg 13 7 64                свой ЛКГ (a c m)
```

## Тесты

```
python -m unittest discover -s tests -v
```

20 тестов проверяют:
- совпадение MT19937 с `random` Python и эталонное первое число 3499211612;
- формулу ЛКГ, максимальный период РСЛОС, вырождение середины квадрата;
- специальные функции: Q(1, x) = e⁻ˣ, Q(1/2, x) = erfc(√x), критические значения χ² и Колмогорова;
- p-значения тестов на контрольных примерах NIST SP 800-22;
- что хорошие датчики проходят тесты, а плохие проваливают;
- плоскости RANDU, линейную сложность, теорему Халла–Добелла.
