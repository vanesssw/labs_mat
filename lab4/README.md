# ЛР №4 «QR и штрих-код»

Программа строит QR-коды и штрих-коды EAN-13 и Code 128, читает их с изображения собственным «сканером» и исследует помехоустойчивость: код можно почеркать, перекрасить, размыть, срезать ему угол и посмотреть, когда он перестаёт читаться.

Выбран второй вариант задания — **самостоятельная реализация** штрих- и QR-кодов. Готовые библиотеки не используются: поле Галуа GF(256), код Рида–Соломона, таблицы стандарта, маски, служебная информация, декодер и сканер написаны с нуля. Корректность проверена так:
- матрицы QR-кодов побитно совпадают с эталонной библиотекой `qrcode` во всех 40 версиях и на всех 4 уровнях коррекции (224 сравнения);
- сгенерированные коды читает независимый сканер OpenCV (60 из 60, включая версию 40);
- штрих-коды EAN-13 совпадают с библиотекой `python-barcode` (300 из 300).

Эталонные библиотеки нужны были только для этих проверок, сама программа их не использует.

| Что умеет | Где |
|---|---|
| QR-код версий 1–40, уровни коррекции L, M, Q, H, режимы: цифровой, буквенно-цифровой, байтовый (UTF-8, кириллица) | вкладка «QR-код» |
| Все этапы построения: биты, блоки, байты Рида–Соломона, чередование, маски и их штрафы, служебная информация | правая часть вкладки «QR-код» |
| Матрица, раскрашенная по назначению модулей; данные без маски; узор каждой маски | вкладка «Устройство QR» |
| EAN-13 (с расчётом контрольной цифры) и Code 128 (наборы B и C) | вкладка «Штрих-коды» |
| 10 видов повреждений, чтение повреждённого кода, сколько байтов исправил Рид–Соломон, серия опытов для L/M/Q/H | вкладка «Помехоустойчивость» |

## Требования

Python 3.8 или новее (проверено на 3.12), библиотеки **Pillow** и **numpy** (обе обычно уже установлены; иначе `pip install pillow numpy`). Интерфейс сделан на `tkinter` из стандартной поставки Python.

## Графический интерфейс

Запуск — двойной щелчок по **`start_gui.bat`** или команда из папки `lab4`:

```
python gui.py
```

### Вкладка «QR-код»
Введите текст, выберите уровень коррекции и нажмите **«Построить»**. Версию и маску можно выбрать вручную или оставить «авто»: тогда берётся наименьшая подходящая версия и маска с наименьшим штрафом. Справа описаны все этапы построения с настоящими числами вашего кода. Кнопка **«Сохранить PNG…»** записывает картинку — её можно отсканировать телефоном.

### Вкладка «Устройство QR»
Матрица текущего кода. Режимы показа:
- «Назначение модулей» — шаблоны поиска, синхронизирующие линии, выравнивающие узоры, служебная информация и номер версии, каждый своим цветом (обозначения справа);
- «Данные без маски»;
- «Узор маски» — какие модули инвертирует маска 0–7;
- «Итоговый код».

### Вкладка «Штрих-коды»
EAN-13: введите 12 цифр, программа вычислит 13-ю (контрольную) и покажет расчёт. Можно ввести и 13 цифр — программа проверит контрольную. Code 128: латиница, цифры и знаки, серии цифр кодируются набором C (по две цифры на символ).

### Вкладка «Помехоустойчивость»
1. Выберите, что портить: QR-код из вкладки 1, штрих-код из вкладки 3 или **«Картинку из файла…»**.
2. Выберите вид повреждения и силу (ползунок 0–1).
3. Нажмите **«Испортить и прочитать»**.

Справа появится результат сканирования: найденные шаблоны поиска, сколько бит служебной информации и сколько байтов в каждом блоке исправил код Рида–Соломона (и сколько мог). Кнопка **«Серия опытов L/M/Q/H»** строит QR-код на четырёх уровнях коррекции, портит его всё сильнее (по 3 попытки на точку) и рисует график доли удачных чтений.

Виды повреждений: почеркать ручкой, клякса/логотип в центре, срезать правый нижний или левый верхний угол, размыть, изменить цвета, снизить контраст, инвертировать цвета, шум «соль и перец», повернуть.

## Командная строка

```
python qrtool.py qr "Привет, мир!" -l H -o qr.png       построить QR-код
python qrtool.py qr "HELLO WORLD" -l Q --explain         с объяснением всех этапов
python qrtool.py ean13 460123456789 -o ean.png           EAN-13
python qrtool.py code128 "LAB4 2026" -o c128.png         Code 128
python qrtool.py scan qr.png                             прочитать код с картинки
python qrtool.py damage qr.png blot 0.2 -o bad.png       испортить картинку
python qrtool.py experiment "текст" scribble --max 0.6   серия опытов L/M/Q/H
```

## Тесты

```
python -m unittest discover -s tests -v
```

20 тестов проверяют:
- арифметику GF(256) и код Рида–Соломона: исправление до ⌊n/2⌋ ошибок, обнаружение большего числа;
- известные контрольные значения: байты «HELLO WORLD», служебную информацию, номер версии 7;
- согласованность таблиц для всех 40 версий;
- что каждый код читается обратно во всех режимах и уровнях, с любой маской;
- что ⌊n/2⌋ испорченных байтов в каждом блоке исправляются, а на один больше — уже нет;
- EAN-13 и Code 128;
- сканер: цвета, инверсию, поворот, шум; уровень H выдерживает кляксу, на которой L сдаётся.
