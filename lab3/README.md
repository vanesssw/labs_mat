# ЛР №3 «Помехоустойчивое кодирование»

Программа строит групповые и циклические помехоустойчивые коды, кодирует сообщения, проверяет принятые комбинации по синдрому (остатку) и исправляет ошибки. Она решает все три задания методички по шагам для любого варианта и показывает передачу текста через канал с помехами.

| Задание | Что делает программа | Мой вариант (№ 1, «Группа 1») |
|---|---|---|
| **1. Групповой код (9,5)** | контрольные соотношения, матрицы G и H, избыточный код, синдромы принятых комбинаций, номер ошибочного разряда, двукратные ошибки с тем же синдромом | 10101 → 101010110; комбинация 1: синдром 0011, ошибка в разряде 1; комбинация 2: синдром 0111, ошибка двукратная (например, разряды 1 и 7) |
| **2. Код для 18 комбинаций, исправляющий одиночные и двойные ошибки** | число разрядов по границам Хэмминга и Варшамова–Гильберта, подбор матрицы перебором, проверка d0, таблица опознавателей | код (13,5), d0 = 5; (12,5) невозможен; 91 опознаватель, все различны |
| **3. Циклический код** | деление «столбиком» на K(x), образующая матрица двумя способами, избыточный код, остаток принятой комбинации, исправление циклическими сдвигами | K(x) = x⁵ + x² + 1; 101101001 → 10110100100010; остаток 10011 — однократной ошибкой быть не может; двукратные: разряды 3 и 7, 4 и 13 |

## Требования

Только Python 3.8 или новее (проверено на 3.12). Сторонние библиотеки не нужны: интерфейс сделан на `tkinter`, который входит в стандартную поставку Python для Windows.

## Графический интерфейс

Запуск — двойной щелчок по **`start_gui.bat`** или команда из папки `lab3`:

```
python gui.py
```

При запуске уже загружен мой вариант. В каждой вкладке задания слева — исходные данные, справа — полное решение по шагам.

### Вкладка «1. Групповой код»

1. Выберите номер варианта (табл. 2.1, от 1 до 18) и «Группу» 1 или 2. Матрица P, информационная часть и две принятые комбинации подставятся из методички (табл. 2.2 — по последней цифре номера).
2. Любое поле можно изменить вручную и нажать **«Решить»**.
3. Справа появится решение: образующая матрица, распределение весов и d0, контрольные соотношения, проверочная матрица H, формирование избыточного кода, проверка обеих комбинаций по синдрому, таблица синдромов одиночных ошибок и двукратные ошибки с тем же синдромом.

### Вкладка «2. Код на 18 комбинаций»

Задайте число комбинаций M (по методичке 18) и кратность исправляемых ошибок s (по методичке 2), нажмите **«Построить код»**. Программа найдёт код минимальной длины и покажет таблицу границ, проверочную матрицу, все кодовые комбинации и таблицу опознавателей. При s = 3 и s = 4 получаются таблицы опознавателей для трёх- и четырёхкратных ошибок (это варианты 2 и 3 задания №2).

### Вкладка «3. Циклический код»

Выберите вариант табл. 2.3 (от 0 до 9) или введите свой образующий многочлен, информационную часть и проверяемую комбинацию. Справа: свойства K(x) (неприводимость, период), образующая матрица остатками и умножением, деление «столбиком», остаток принятой комбинации, таблица остатков одиночных ошибок, двукратные ошибки и исправление циклическими сдвигами по алгоритму методички.

### Блок «Попробуй сам» (во вкладках 1–3)

Введите сообщение и нажмите **«Закодировать»**. Щелчок по разряду в строке «Принято» инвертирует его, то есть вносит ошибку. Программа сразу показывает синдром (остаток) и что сделал декодер:
- зелёный — ошибка исправлена верно;
- оранжевый — ошибка обнаружена, но не исправлена;
- красный — декодер ошибся или не заметил ошибку (ошибок больше, чем код может исправить).

### Вкладка «Канал с помехами»

Введите текст, задайте вероятность ошибки бита p и нажмите **«Передать по каналу»**. Текст передаётся без кодирования и тремя кодами из вкладок 1–3. В таблице показано, сколько битов исказил канал, сколько блоков исправлено и сколько ошибок осталось. Ниже — принятые тексты с выделенными ошибками и сравнение теоретической вероятности неисправленного блока с опытом на 10 000 блоках.

## Командная строка

Решения заданий в виде текста (тот же текст, что в программе):

```
python solve.py                       все три задания для варианта № 1, «Группа 1»
python solve.py -n 7 -g 2             вариант 7, «Группа 2»
python solve.py -t 3                  только задание 3
python solve.py -t 2 -M 18 -s 3       задание 2 для трёхкратных ошибок
python solve.py -o решение.txt        сохранить в файл
```

## Тесты

```
python -m unittest discover -s tests -v
```

23 теста проверяют:
- ручной расчёт моего варианта для всех трёх заданий;
- что G·Hᵀ = 0 для всех 18 вариантов табл. 2.1 в обеих группах;
- что код (9,5) исправляет любую одиночную ошибку, а код (13,5) — любую двойную;
- деление многочленов (a = q·g + R), неприводимость и период многочленов;
- что алгоритм исправления сдвигами исправляет любую одиночную ошибку для укороченного кода (14,9) и для настоящих циклических кодов (7,4) и (15,11);
- что кода (12,5) с d0 = 5 нет, хотя граница Хэмминга его допускает;
- передачу текста через канал.
