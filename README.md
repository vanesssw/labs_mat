# Лабораторные работы «Кодирование и шифрование»

Четыре лабораторные работы на Python. Каждая лежит в своей папке и состоит из программы с графическим интерфейсом, командной строки, автоматических тестов, отчёта и конспекта для защиты.

| ЛР | Тема | Что внутри | Папка |
|---|---|---|---|
| **№2** | Методы упаковки данных | архиватор: RLE, Хаффман, Шеннон–Фано, LZW | [lab2](lab2/) |
| **№3** | Помехоустойчивое кодирование | групповые и циклические коды, синдром, исправление ошибок, канал с помехами | [lab3](lab3/) |
| **№4** | QR и штрих-код | QR-код с кодом Рида–Соломона, EAN-13, Code 128, сканер, опыты с повреждениями | [lab4](lab4/) |
| **№5** | Генераторы псевдослучайных чисел | 7 датчиков (от середины квадрата до вихря Мерсенна и BBS), 14 статистических тестов | [lab5](lab5/) |

Подробное описание каждой работы — в `README.md` внутри её папки.

## Требования

- **Python 3.8 или новее** (проверено на 3.12). При установке на Windows оставьте галочку «tcl/tk and IDLE», тогда будет `tkinter`, на котором сделан интерфейс.
- ЛР №2 и №3 сторонних библиотек не требуют.
- ЛР №4 и №5 используют **Pillow** и **numpy**:

```
pip install pillow numpy
```

На Linux `tkinter` ставится отдельно: `sudo apt install python3-tk`.

## Быстрый старт

```
git clone https://github.com/vanesssw/labs_mat.git
cd labs_mat
pip install pillow numpy
```

### Графический интерфейс

Проще всего — двойной щелчок по **`start_gui.bat`** в папке нужной работы. Или из консоли:

```
cd lab4
python gui.py
```

### Командная строка

Команды запускаются из папки работы. Примеры:

```
cd lab2
python archiver.py c test_files\01_text_ru_cp1251.txt -m lzw     сжать файл методом LZW
python archiver.py b test_files                                  сравнить все методы

cd lab3
python solve.py -n 7 -g 2                                        решить вариант 7, «Группа 2»

cd lab4
python qrtool.py qr "Привет, мир!" -l H -o qr.png                построить QR-код
python qrtool.py scan qr.png                                     прочитать его с картинки

cd lab5
python prngtool.py list                                          список датчиков
python prngtool.py test randu                                    проверить качество RANDU
```

Полный список команд — в README каждой работы и по ключу `--help`, например `python qrtool.py --help`.

### Тесты

Из папки работы:

```
python -m unittest discover -s tests -v
```

Все работы сразу (PowerShell, из корня репозитория):

```
foreach ($d in 'lab2','lab3','lab4','lab5') { Push-Location $d; python -m unittest discover -s tests; Pop-Location }
```
